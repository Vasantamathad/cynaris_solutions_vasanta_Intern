# Week 3 Day 3 – Excel for Analysis

## Objective
Use Excel PivotTables and Power Query for business data analysis and automated reporting.

## Tasks Completed

1. Created PivotTables to summarize sales and profit by region and quarter.
2. Calculated profit margin and quarterly growth percentages.
3. Used Power Query to import and append multiple CSV datasets.
4. Created PivotCharts to visualize quarterly sales and profit by region.
5. Added slicers for Region, Quarter, and Category.
6. Applied conditional formatting to highlight values.

## Dataset
- Superstore dataset
- Additional dataset: superstore_extra.csv
- Combined rows: 10,006

## Tools Used

- Power Query
- PivotTables
- PivotCharts

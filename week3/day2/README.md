# Week 3 – Day 2: DAX Basics

## Learning Objective
Understand and implement DAX (Data Analysis Expressions) in Power BI.

## Topics Covered
- Introduction to DAX
- Measures and Calculated Columns
- CALCULATE function
- DATESYTD function
- EARLIER function
- Row Context and Filter Context
- Context Transition

## Practical Tasks
- Create DAX measures.
- Calculate Electronics Sales.
- Calculate Year-to-Date Sales.
- Create a Running Total.
- Calculate Profit Margin.
- Test DAX calculations using Power BI visuals.

## Tools Used
- Microsoft Power BI Desktop
- DAX
- Visual Studio Code

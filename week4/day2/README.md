# Week 4 – Day 2: Probability

## Overview
This project explores fundamental probability concepts and statistical distributions used in data analysis and business forecasting. Practical exercises were performed using Python, NumPy, Pandas, Matplotlib, and SciPy.

## Objectives
- Calculate basic, joint, and conditional probabilities.
- Understand and visualize the normal distribution.
- Explore the 68–95–99.7 rule.
- Simulate binomial distributions using NumPy.
- Demonstrate the Central Limit Theorem using sampling simulations.

## Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- SciPy
- Jupyter Notebook (VS Code)

## Tasks Completed

### Task 1: Basic Probability
- Created a contingency table for coupon usage and repeat purchases.
- Calculated P(A), P(B), P(A ∩ B), P(B | A), and P(A | B).
- Interpreted probability results in a business context.

### Task 2: Normal Distribution
- Generated and plotted a normal distribution.
- Visualized the 68–95–99.7 rule.
- Identified the relationship between mean and standard deviation.

### Task 3: Binomial Distribution
- Simulated 1,000 experiments using NumPy.
- Used 100 trials per experiment with a success probability of 20%.
- Compared the simulated mean with the theoretical expected value.

### Task 4: Central Limit Theorem
- Generated an exponential population.
- Created 1,000 random samples of size 50.
- Calculated sample means.
- Compared the population distribution with the distribution of sample means.
